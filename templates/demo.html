Atlassian Design System Components

The Atlassian Design System provides a comprehensive set of components that ensure consistency across all Atlassian products.

Key Principles:

  • Consistency: All components follow the same design patterns
  • Accessibility: Components are built with accessibility in mind
  • Scalability: Components work across different screen sizes
  • Performance: Optimized for fast loading and smooth interactions

Components Included:

  • Buttons (Primary, Secondary, Subtle, Link, Warning, Danger)
  • Forms with validation states
  • Modals and dialogs
  • Banners and notifications
  • Lozenge status indicators
  • Loading states and skeletons
  • Dropdown menus
  • Tooltips
  • Avatars
  • Progress bars and indicators
  • Toggle switches
  • Enhanced radio buttons and checkboxes
  • Pagination controls
  • Toast notification system
  • Enhanced badges
  • Navigation components
  • Date picker with calendar
  • Enhanced search with autocomplete
  • Sortable data tables
  • Step indicators and progress flows
  • Sidebar navigation
  • Breadcrumb navigation
  • File upload with drag & drop
  • Context menus
  • Filter panels
  • Inline editing components
  • Timeline/activity feeds
  • Comment threading system
  • Notification bell dropdown
  • Settings panels
  • Keyboard shortcuts modal
  • And many more...
