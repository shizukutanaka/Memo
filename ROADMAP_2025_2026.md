### 2.1 End-to-End Encryption

**Status**: Research Complete ✅
**Priority**: High
**Effort**: High (4-6 weeks)

**Research Findings** (Standard Notes, Reflect, Dev Tech Insights):
- XChaCha20-Poly1305 is industry-standard
- Zero-knowledge architecture required
- Hardware-backed keystores important

**Architecture**:
```python
# encryption.py
from cryptography.hazmat.primitives.ciphers.aead import ChaCha20Poly1305
import os

class MemoEncryption:
    """End-to-end encryption for memo content."""

    def __init__(self, master_password: str):
        """Initialize with user's master password."""
        # PBKDF2 derive key from password (50,000+ iterations)
        self.key = self._derive_key(master_password)

    def _derive_key(self, password: str) -> bytes:
        """Derive encryption key from password using PBKDF2."""
        from cryptography.hazmat.primitives import hashes
        from cryptography.hazmat.primitives.kdf.pbkdf2 import PBKDF2

        kdf = PBKDF2(
            algorithm=hashes.SHA256(),
            length=32,
            salt=os.urandom(16),
            iterations=480000,  # 2025 standard
        )
        return kdf.derive(password.encode())

    def encrypt_memo(self, memo_id: str, content: str) -> bytes:
        """Encrypt memo content with authentication."""
        cipher = ChaCha20Poly1305(self.key)
        nonce = os.urandom(12)
        ciphertext = cipher.encrypt(nonce, content.encode(), memo_id.encode())
        return nonce + ciphertext

    def decrypt_memo(self, memo_id: str, encrypted: bytes) -> str:
        """Decrypt memo content with verification."""
        cipher = ChaCha20Poly1305(self.key)
        nonce = encrypted[:12]
        ciphertext = encrypted[12:]
        plaintext = cipher.decrypt(nonce, ciphertext, memo_id.encode())
        return plaintext.decode()
```

**Features**:
- Master password protection
- Per-memo encryption keys
- Cloud sync with encrypted at-rest
- Zero-knowledge server (optional)

**Dependencies**:
- `cryptography>=42.0.0`
- `argon2-cffi>=23.1.0` (for key derivation)

```python
# mfa.py
import pyotp
import qrcode

class MFA:
    def setup_totp(self) -> tuple[str, str]:
        """Set up TOTP (Google Authenticator compatible)."""
        secret = pyotp.random_base32()
        totp = pyotp.TOTP(secret)

        # Generate QR code for scanning
        qr = qrcode.QRCode()
        qr.add_data(totp.provisioning_uri(name='user', issuer_name='Memo'))
        qr.make()

        return secret, qr.svg()

    def verify_totp(self, secret: str, code: str) -> bool:
        """Verify TOTP code."""
        totp = pyotp.TOTP(secret)
        return totp.verify(code)
```
